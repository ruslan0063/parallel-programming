Лабораторная работа №1 заключается в разработке программы для умножения квадратных матриц. Программа написана на языке C++ и использует технологию OpenMP для распределения вычислений между несколькими потоками. Программа считывает матрицы из файлов, выполняет их умножение, сохраняет результат и выводит время выполнения.

Основные файлы проекта:

`main.cpp` — основная часть программы, где реализовано чтение файлов, параллельное умножение матриц и замер времени работы.
`CMakeLists.txt` — файл для сборки проекта.
`generate.py` — создает тестовые матрицы со случайными числами.
`verify.py` — проверяет правильность результатов через библиотеку NumPy.
`analytics.py` — строит график производительности программы.
`results.txt` — сохраняет результаты тестов.
`performance_graph.png` — график зависимости времени выполнения от размера матриц.

Для параллелизации использовалась директива #pragma omp parallel for, которая позволяет выполнять вычисления одновременно в нескольких потоках. Для проверки корректности вычислений использовались Python и библиотека NumPy, а для построения графиков — Matplotlib.
